# KnowledgePilot

Agentic RAG Research and Document Intelligence Platform

## Overview

KnowledgePilot is a full-stack AI application that allows users
to upload documents, search their knowledge base, ask questions,
and perform multi-step research using an agentic RAG pipeline.

## Tech Stack

- Next.js
- TypeScript
- FastAPI
- Python
- MongoDB
- MongoDB Atlas Vector Search
- LLMs
- Embeddings
- Docker
- Git
